# 第二阶段第三步：WAL 基础设施实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在 Java 17 下交付按交易对追加、每次写入强制刷盘、带 CRC32 校验、支持文件滚动和安全读取尾部不完整记录的本地 WAL。

**架构：** `WalCodec` 是唯一的确定性 JSON 和校验实现；`FileWalWriter` 负责一个物理文件的追加与落盘；`FileWalReader` 负责校验并区分可忽略尾部与中间损坏；`WalManager` 依据交易对独立管理当前文件和滚动。WAL 仅记录 `MatchingCommand`，不调用撮合、不推进序列、不依赖 Kafka。

**技术栈：** Java 17、Jackson（由现有 `cex-common-web` 的 Spring Boot Web 依赖提供）、NIO `FileChannel`、CRC32、JUnit Jupiter、AssertJ、Maven。

```java
public record WalRecord(
        long sequence, String commandId, String orderId, String userId, String symbol,
        CommandType commandType, MatchOrder.Side side, long price, long quantity,
        long timestamp, long checksum) {

    public static WalRecord from(MatchingCommand command) {
        return new WalRecord(command.sequence(), command.commandId(), command.orderId(),
                command.userId(), command.symbol(), command.commandType(), command.side(),
                command.price(), command.quantity(), command.timestamp(), 0L);
    }

    public WalRecord withChecksum(long value) {
        return new WalRecord(sequence, commandId, orderId, userId, symbol, commandType,
                side, price, quantity, timestamp, value);
    }
}

public String encode(WalRecord record) {
    String payload = payloadJson(record);
    long checksum = crc32(payload.getBytes(StandardCharsets.UTF_8));
    return payload.substring(0, payload.length() - 1) + ",\"checksum\":" + checksum + "}";
}
```

`WalCodec` 使用 `JsonGenerator` 以固定字段顺序生成 payload JSON，`decode` 读取 `JsonNode` 后重建无 checksum 的 `WalRecord`、重新编码并比对 CRC32。所有解析或校验失败统一抛出 `WalCorruptionException`；`null side` 必须编码成 JSON `null`。

- [ ] **步骤 3：编写最少的单文件写入实现**

```java
public interface WalWriter extends AutoCloseable {
    void append(WalRecord record);
    void flush();
    long writtenBytes();
    @Override
    void close();
}

public void append(WalRecord record) {
    ensureOpen();
    byte[] line = (codec.encode(record) + "\n").getBytes(StandardCharsets.UTF_8);
    try {
        ByteBuffer buffer = ByteBuffer.wrap(line);
        while (buffer.hasRemaining()) {
            channel.write(buffer);
        }
        channel.force(true);
        writtenBytes += line.length;
    } catch (IOException exception) {
        throw new WalException("WAL 写入或刷盘失败: " + path, exception);
    }
}
```

构造器创建父目录，并使用 `CREATE`、`WRITE`、`APPEND` 打开 `FileChannel`；`writtenBytes` 从已有文件大小初始化。`flush()` 调用 `force(true)`，`close()` 先刷盘再关闭；对已关闭写入或 I/O 异常抛出 `WalException`。

- [ ] **步骤 3：编写最少的读取和损坏区分实现**

```java
public interface WalReader {
    WalReadResult read(String symbol);
}

public record WalReadResult(List<WalRecord> records, boolean incompleteTail) {
    public WalReadResult {
        records = List.copyOf(records);
    }
}

public WalReadResult readFile(Path file) {
    List<String> lines = Files.readAllLines(file, StandardCharsets.UTF_8);
    List<WalRecord> records = new ArrayList<>();
    for (int index = 0; index < lines.size(); index++) {
        try {
            records.add(codec.decode(lines.get(index)));
        } catch (WalCorruptionException exception) {
            if (index == lines.size() - 1) {
                return new WalReadResult(records, true);
            }
            throw exception;
        }
    }
    return new WalReadResult(records, false);
}
```

`read(symbol)` 仅接受非空 symbol，扫描 `<root>/<symbol>` 内匹配 `wal-\\d{6}.log` 的常规文件，按文件编号升序读取并合并结果。合并记录的 sequence 必须严格递增；否则抛出 `WalCorruptionException`。任何 I/O 异常包装为 `WalException`。

```java
public void append(WalRecord record) {
    byte[] line = (codec.encode(record) + "\n").getBytes(StandardCharsets.UTF_8);
    ActiveWriter active = activeWriters.computeIfAbsent(record.symbol(), this::openLatestWriter);
    if (active.writer().writtenBytes() > 0 && active.writer().writtenBytes() + line.length > maxFileSizeBytes) {
        active.writer().close();
        active = openWriter(record.symbol(), active.fileNumber() + 1);
        activeWriters.put(record.symbol(), active);
    }
    active.writer().append(record);
}
```

`WalManager` 校验根目录和 `maxFileSizeBytes > 0`，使用 `Map<String, ActiveWriter>` 隔离交易对。它通过扫描现有编号文件找到继续写入的最新文件；没有文件时创建 `wal-000001.log`。`close()` 关闭所有活动写入器，即使其中一个关闭失败也继续关闭其他写入器，并在结束时抛出首个 `WalException`。
